# 🎮 Deadlock vs. Counter-Strike 2: Market Trajectory & Sustainability Analysis

A data-driven comparative study evaluating Valve's emerging hero-shooter MOBA title **Deadlock** against the enduring industry benchmark **Counter-Strike 2**.

---

## 📌 Project Overview
- **Objective:** Analyze whether Deadlock's core loop, genre mechanics, and player retention trends can match the multi-decade sustainability of Counter-Strike 2.
- **Data Source:** Live data integration via SteamSpy API & Official Steam Web API.
- **Methodology:** Heuristic sustainability scoring model & 24-month probabilistic scenario forecast.

---

## 📊 Key Findings & Strategic Insights

### 1. Accessibility vs. Depth
- **Counter-Strike 2:** Thrives on immediate accessibility and intuitive mechanics ("easy to learn, hard to master"), allowing effortless long-term retention across casual and competitive cohorts.
- **Deadlock:** Integrates 4-lane macro management, laning phases, and itemization builds, naturally establishing a higher skill floor that caps mass casual adoption.

### 2. 24-Month Trajectory Scenarios
- **Optimistic (CS-Tier):** Requires broad esports adoption, aggressive post-launch marketing, and rapid meta balancing.
- **Realistic (Dota/TF2-Tier Retention):** An initial post-launch surge followed by natural stabilization around 100k–150k dedicated core players.
- **Pessimistic (Hype Decay):** High churn rate driven by mechanical fatigue, leading to niche containment.
